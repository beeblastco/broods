# Gaps

Places where the model and today's TypeScript disagree, or where the code looks wrong. Each entry has
an id that a `test.failing` title or a Lean docstring can cite. An entry goes away only when the code
or a decision changes.

Status: `open` (the code still disagrees), `decide` (needs an owner decision).
